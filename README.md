# curtainbox

Просмотр фото на весь экран: фото вырастает из превью и сворачивается обратно, листается шторкой, увеличивается и тянется с инерцией. Без зависимостей: один файл JS и один CSS, ~16 КБ в gzip вместе с комментариями.

*A full-screen photo viewer: the photo grows out of its thumbnail and folds back into it, pages with a curtain wipe, zooms and pans with inertia. No dependencies.*

## Что умеет

- **Из превью и обратно.** Фото вырастает из превью на странице и при закрытии садится точно в него, с учётом `object-fit` и `object-position`. Если превью не видно на экране или его что-то закрывает, фото просто растворяется.
- **Сразу без ожидания.** Пока грузится большое фото, на экране превью нужного размера, а сверху бежит тонкая полоска. Большое фото встаёт на место превью без скачка. Соседние фото подгружаются заранее.
- **Листание шторкой.** Новое фото открывается вертикальной шторкой со стороны листания и доезжает на место, старое уплывает в другую сторону. При свайпе шторка идёт за пальцем или мышью, на отпускании доезжает или откатывается. Ещё листают стрелки, клавиши ←/→ и миниатюры снизу.
- **Зум.** Щелчок увеличивает ступенями ×2, ×4… до натурального размера фото, двойной тап увеличивает к месту тапа, колесо мыши и щипок (на телефоне и тачпаде) масштабируют плавно. Увеличенное фото тянется с инерцией и мягко пружинит у краёв. Если листать увеличенное фото, следующее откроется в том же масштабе.
- **Закрытие:** крестик, Esc, щелчок по фону, кнопка «Назад» в браузере, свайп вверх или вниз на телефоне.
- **Свой адрес.** У открытого окна адрес `#группа-номер`: «Назад» закрывает окно, а ссылка с таким адресом открывает его сразу на нужном фото.
- Открывается и щипком: развести два пальца на превью.
- Фокус не уходит из окна, у кнопок есть подписи для экранных дикторов, учитывается `prefers-reduced-motion`.
- Аккуратно с Safari на iPhone: анимации покадровые, а не CSS-переходы (те мигали белым), щипок не масштабирует страницу.

## Подключение

```html
<link rel="stylesheet" href="curtainbox.css">
<script src="curtainbox.js"></script>
```

Или через сборщик: `require('curtainbox')` / `import Curtainbox from 'curtainbox'` (UMD).

## Разметка

Ссылка на большое фото, внутри превью. Ссылки с одинаковым `data-lightbox` листаются вместе:

```html
<a data-lightbox="gallery" href="photo-1-large.jpg"><img src="photo-1-thumb.jpg" alt="…"></a>
<a data-lightbox="gallery" href="photo-2-large.jpg"><img src="photo-2-thumb.jpg" alt="…"></a>
```

```js
Curtainbox.init();
```

Превью и большое фото должны быть одних пропорций: по превью окно сразу рассчитывает размер фото. Обрезать превью на странице через `object-fit: cover` можно.

Живой пример — [`example/index.html`](example/index.html).

## Параметры

```js
Curtainbox.init({
  labels: { dialog: 'Фото', close: 'Закрыть', prev: 'Предыдущее фото', next: 'Следующее фото', thumb: 'Фото {n}' }
});
```

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `attribute` | `'data-lightbox'` | атрибут ссылок, его значение — имя группы |
| `hash` | `true` | свой адрес `#группа-номер` у окна; `false` — история браузера не трогается |
| `pinchOpen` | `true` | открывать окно щипком на превью |
| `labels` | английские | подписи для экранных дикторов: `dialog`, `close`, `prev`, `next`, `thumb` (`{n}` — номер фото) |
| `frame(link)` | ссылка | элемент, в который сворачивается фото при закрытии |
| `resolve(link)` | — | какую ссылку открыть вместо нажатой; `null` — ничего не открывать. Пригодится, если превью само листается и под нажатием может оказаться не то фото |
| `onOpen(info)` | — | окно открылось |
| `onClose(info)` | — | окно начало закрываться, `info` — `{ group, index, link }`. Если здесь пролистать галерею на странице к этому фото, оно свернётся прямо в неё |

То же, что `onClose`, приходит событием `curtainbox:close` на `document` (`event.detail`).

## Методы

- `Curtainbox.open('gallery', 2)` — открыть третье фото группы; `Curtainbox.open(link)` — открыть с этой ссылки;
- `close()`, `next()`, `prev()`, `goTo(i)`, `isOpen()`;
- `destroy()` — снять обработчики и убрать окно со страницы.

## Стили

Цвета и размеры — CSS-переменные на `.curtainbox`, их можно переопределить:

```css
.curtainbox {
  --curtainbox-bg: #111;
  --curtainbox-ink: #fff;
  --curtainbox-btn-bg: #222;
  --curtainbox-btn-hover-bg: #e30613;
}
```

Основные: `--curtainbox-bg` (фон), `--curtainbox-ink` (значки, рамка активной миниатюры, полоска загрузки), `--curtainbox-muted` (счётчик), `--curtainbox-btn-bg`, `--curtainbox-btn-hover-bg`, `--curtainbox-btn-hover-ink`, `--curtainbox-btn-size`, `--curtainbox-thumb`, `--curtainbox-radius`, `--curtainbox-pad` (поля вокруг фото), `--curtainbox-z`, `--curtainbox-font`. Полный список — в начале `curtainbox.css`.

Пока окно открыто, у `<html>` класс `curtainbox-lock` (`overflow: hidden`): страница под окном не прокручивается.

## Браузеры

Современные браузеры с Pointer Events и `clip-path: inset()`: Chrome, Edge, Firefox, Safari 13.1+ (macOS и iOS).
